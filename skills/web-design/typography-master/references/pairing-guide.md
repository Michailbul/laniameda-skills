# Font Pairing Guide

## Core Principle: Contrast, Not Conflict

A great font pair creates **visual tension through contrast** while maintaining **harmony through shared proportions or era**. The worst pairings are fonts that are too similar (boring) or too chaotic (jarring).

---

## The 4 Types of Effective Pairings

### 1. Serif + Sans (Classic Contrast)
The most reliable combination. Use a serif for headings (authority, character) and sans-serif for body (legibility, neutrality). Or flip it.

**Rules:**
- Ensure the x-heights are similar (avoids awkward proportion shifts)
- The sans should be neutral enough to not compete with the serif's character
- Avoid pairing two fonts from different historical eras unless intentional

**Examples:**
- `Playfair Display + Source Sans 3` — editorial elegance
- `DM Serif Display + DM Sans` — same family, guaranteed harmony
- `Cormorant Garamond + Jost` — old-world heading, modern body
- `Fraunces + Figtree` — expressive heading, clean body

---

### 2. Display + Workhorse
Use a bold expressive display font for headlines, a utility-grade workhorse for everything else.

**Rules:**
- The workhorse should essentially disappear — readers shouldn't notice it
- Display font carries all the brand personality
- Limit display font to headings only (H1, H2 max)

**Examples:**
- `Clash Display + General Sans` — premium landing page
- `Syne + Inter` — creative agency
- `Bebas Neue + Mulish` — impact + clarity
- `Unbounded + DM Sans` — bold geometric + clean

---

### 3. Same Family Superfamily
Many type designers release a serif + sans as matched pairs. These are foolproof.

**Superfamily pairs:**
- `DM Serif Display + DM Sans` ✓
- `Source Serif 4 + Source Sans 3` ✓
- `IBM Plex Serif + IBM Plex Sans` ✓
- `Roboto Slab + Roboto` ✓

**When to use:** When you need guaranteed harmony and don't want to risk a mismatch. Slightly safer but can feel expected.

---

### 4. Mono Accent Pairing
Use a monospace as an accent font (labels, badges, code, timestamps) with a primary sans or serif. 

**Rules:**
- Mono should only appear in small UI elements and captions
- Never use mono for body copy
- Creates a technical/developer-friendly feeling

**Examples:**
- `Inter + JetBrains Mono` (accent) — dev tools
- `Space Grotesk + Space Mono` (accent) — Web3, experimental
- `Satoshi + IBM Plex Mono` (accent) — fintech

---

## Pairing Anti-Patterns (What NOT to Do)

❌ **Two decorative fonts** — Both compete for attention. Always pair decorative + neutral.

❌ **Two fonts from the same classification with similar proportions** — Poppins + Nunito look almost identical. Pointless pairing.

❌ **Pairing fonts from incompatible historical eras without intention** — A Victorian display font with a Bauhaus geometric sans looks confused, not eclectic.

❌ **Too many fonts** — Maximum 2 font families per design. 3 only with a clear role for each (display, body, mono-accent).

❌ **Same font for heading and body with only weight change** — This is technically fine for minimal design, but doesn't count as a "pairing."

## Vibe-to-Pairing Quick Reference

| Project vibe | Heading | Body | Notes |
|-------------|---------|------|-------|
| **Luxury / Fashion** | Cormorant Garamond or Bodoni Moda | Raleway or Jost | Thin weights, lots of whitespace |
| **B2B SaaS** | DM Sans or Plus Jakarta Sans | Inter | Often single-font, just weight variation |
| **Creative Agency** | Syne or Clash Display | General Sans or Satoshi | Bold personality up front |
| **Fintech / Trustworthy** | DM Serif Display | DM Sans or Source Sans 3 | Authority + clarity |
| **Editorial / Blog** | Fraunces or Playfair Display | Lora or Source Serif 4 | Warm, readable, literary |
| **Dev Tools / Tech** | Space Grotesk or Mona Sans | Inter | Techy feel, monospace accent ok |
| **Wellness / Health** | Nunito or Figtree | Mulish | Rounded, approachable, calming |
| **E-commerce** | Outfit or DM Sans | Source Sans 3 | Neutral, product-forward |
| **Startup / Product** | Cabinet Grotesk or Satoshi | General Sans | Premium, contemporary |
| **Bold / Expressive** | Unbounded or Bebas Neue | Inter | Make a statement |

## Testing a Pairing

When evaluating whether two fonts work together, test them at:
1. **Hero scale** (80px heading + 20px body) — most important test
2. **Card scale** (28px heading + 15px body)
3. **Dense UI** (14px label + 13px body)

If they look good at all three scales, they work.
